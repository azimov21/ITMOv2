# ReAct

Файл ведёт OpenCode по вашим запросам. Агент записывает фактические результаты экспериментов и вносит изменения в связанные файлы. Свою оценку сообщайте ему в чате; вручную заполнять шаблон не нужно.

- Цель: подтвердить входы нагрузочных сценариев — валидацию и лимит размера (без них пороги `tests_load` висят в воздухе)
- Доступные входы: `TRAINING_PR.diff` (`api.py:35-37`), правила `API-1`/`REL-1` из `context.md`
- Разрешённые действия: читать diff и `context.md`; слать тестовые `POST` с `{}` / мусором / большим diff; мокать `LLM.generate`
- Запрещённые действия: боевые секреты, сеть, правка кода сервиса, чтение удалённого `CASE.md`
- Максимальное число шагов: 4
- Условие остановки и вопроса человеку: стоп, когда оба входа (`400/422` и `413`) подтверждены; если мок висит дольше 10s — стоп и вопрос человеку

## Запрос

Обойди стык `api.py → review_service.py` шагами: действие → наблюдение → решение. Начни с `POST {}`, затем большой diff, затем мок с ошибкой. После каждого шага решай: продолжить или остановиться. В конце скажи, что поправить в строке `tests_integration.md`.
